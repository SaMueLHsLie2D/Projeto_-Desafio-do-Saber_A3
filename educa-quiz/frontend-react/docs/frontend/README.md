# Documentação do Front-end

Esta pasta contém a explicação do frontend do projeto `Desafio do Saber`.
O conteúdo está dividido em seções que ajudam a entender a estrutura de pastas e os principais arquivos.

- `estrutura.md` - visão geral de organização das pastas e arquivos.
- `src.md` - descrição da pasta `src` e arquivos principais.
- `src-pages.md` - explicação das páginas do app.
- `src-pages-detalhado.md` - explicação detalhada de cada página.
- `src-components.md` - componentes reutilizáveis e layout.
- `src-context.md` - contexto de usuário e estado global.

Use este material para estudar como o front está estruturado e como as páginas se comunicam.
